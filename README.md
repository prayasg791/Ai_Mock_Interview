# 🚀 AI Mock Interview Platform

A full-stack real-time AI-powered mock interview platform where users can collaboratively code in live rooms, run JavaScript code, and receive AI-generated feedback instantly.

---

# 🌐 Live Demo

## Frontend
https://ai-mock-interview-black-beta.vercel.app

## Backend
https://ai-mock-interview-5mmv.onrender.com

---

# ✨ Features

- 🔐 JWT Authentication (Login/Register)
- 🚪 Secure Logout with Token Blacklisting
- 🛡️ Protected Routes
- 👨‍💻 Real-time Collaborative Coding using Socket.io
- 🧠 AI Feedback Generation using Gemini API
- ⚡ JavaScript Code Execution
- 🕘 Interview History Tracking
- 🎨 Modern Responsive UI
- ☁️ Fully Deployed on Vercel + Render

---

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/prayasg791/Ai_Mock_Interview.git
```

---

## 2️⃣ Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## 3️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

---


---

# ▶️ Run Frontend

```bash
cd frontend
npm run dev
```

---

# ▶️ Run Backend

```bash
cd backend
npm start
```

---

# 🧪 Test Realtime Collaboration

1. Open app in two browser tabs/devices
2. Join same room ID
3. Start coding collaboratively in real-time
